## Default Permission

Allows HeriHeriCloud to control the native GStreamer player.

#### This default permission set includes the following:

- `allow-open`
- `allow-play`
- `allow-pause`
- `allow-stop`
- `allow-seek`
- `allow-set-volume`
- `allow-set-muted`
- `allow-set-rate`
- `allow-set-looping`
- `allow-select-audio-track`
- `allow-select-subtitle-track`
- `allow-set-subtitle-uri`
- `allow-get-state`
- `allow-capabilities`
